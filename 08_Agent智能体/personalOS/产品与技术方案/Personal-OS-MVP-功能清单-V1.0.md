# Personal OS MVP｜功能清单

> 版本：V1.0  
> 更新日期：2026-08-10  
> 当前版本：Day 7 已正式验收通过  
> 产品定位：个人本地执行管理工具（iPhone / Expo Go）

## 一、当前 MVP 能做什么

```text
按日期安排任务 → 在今日执行 → 未完成任务自动顺延 → 记录每日复盘 → 查看真实执行结果
```

## 二、已实现功能清单

| 模块 | 功能 | 当前规则 |
| --- | --- | --- |
| 今日 | 查看今日任务 | 显示当天任务；按 P0→P3、同级 `sort_order` 排序 |
| 今日 | 完成 / 取消完成任务 | 今日任务可直接切换；完成状态本地持久化 |
| 今日 | 新增任务 | 可填写标题、日期和 P0—P3 优先级；默认 P2 |
| 今日 | 编辑 / 删除任务 | 修改后同步保存；删除后刷新任务列表 |
| 今日 | 今日重点 | 自动显示排序最前的一条未完成 P0；没有未完成 P0 时显示空状态 |
| 计划 | 按日期查看任务 | 切换日期查看同一份任务数据，不复制任务 |
| 计划 | 创建与维护计划任务 | 可按日期新增、编辑、删除任务 |
| 自动顺延 | 过期未完成任务处理 | 未完成任务自动顺延到今天；完成后不会回写为过去已完成 |
| 历史任务 | 历史已完成任务保护 | 取消历史已完成状态前必须二次确认；避免误改执行记录 |
| 复盘 | 每日复盘填写与保存 | 可填写并保存每日复盘内容，后续可编辑文字内容 |
| 复盘 | 实时任务统计 | 当日尚未保存复盘时，显示当前任务的实时统计 |
| 复盘 | 历史统计快照 | 首次成功保存复盘时冻结任务统计；后续任务变化不自动改写快照 |
| 复盘 | 重复保存保护 | 同一项目、同一日期仅保留一条复盘；再次保存更新内容，不产生重复记录 |
| 复盘 | 保存确认与失败提示 | 首次保存先确认统计冻结；失败不显示成功且允许重试 |
| 复盘 | 习惯数据空状态 | 暂无真实习惯数据时，显示真实空状态，不生成虚假完成率 |
| 数据 | 本地 SQLite 持久化 | 任务、复盘及完成状态在 Reload 与重启 Expo Go 后保留 |
| 稳定性 | 页面刷新与异步保护 | 切换日期或 Tab 后刷新当前数据，避免旧请求覆盖当前页面 |

## 三、当前页面

| 页面 | 作用 |
| --- | --- |
| 今日 | 聚焦当天任务、完成执行、查看今日重点 |
| 计划 | 按日期安排和管理任务 |
| 复盘 | 记录当天复盘，查看实时统计或已保存快照 |
| 我的 | 个人入口页；暂不包含完整项目管理 |

## 四、当前数据规则

1. 任务、计划页与今日页使用同一份任务数据。
2. 任务优先级为 P0、P1、P2、P3；数值越小优先级越高。
3. 历史已完成任务允许纠错，但必须确认；已保存的复盘统计不随之变动。
4. 首次保存复盘代表确认当天统计；之后编辑复盘文字不重新计算统计。
5. 所有当前数据仅保存于本机，不包含账号、云同步或多人协作。

## 五、当前 MVP 不包含的功能

以下内容尚未开发，不应视为当前版本能力：

- 项目新增、编辑、归档、切换与项目进度；
- 完整习惯打卡、习惯统计与提醒；
- 周目标、周计划、周复盘；
- 重复任务、通知提醒与日历同步；
- 复盘草稿、完成复盘状态、手动重算统计快照；
- 历史操作日志；
- 长期目标体系、看板、甘特图或子项目；
- AI 对话、AI 自动排程、AI 自动修改任务；
- 登录、云同步、跨设备同步、App Store 发布。

## 六、下一阶段优先级（未计入当前版本）

| 优先级 | 候选模块 | 目的 |
| --- | --- | --- |
| P0 | 项目管理最小闭环 | 让健康、英语、求职、万万酱、Personal OS 开发等任务有真实归属 |
| P1 | 周目标 / 周复盘 | 从单日执行延伸到每周推进与复盘 |
| P2 | 习惯系统 | 形成可计算、可复盘的日常习惯数据 |
| P3 | AI 决策能力 | 基于项目、任务和复盘等真实数据给出执行建议 |

## 七、版本结论

当前 MVP 已具备个人日常执行管理的最小闭环，适合开始真实使用并积累任务与复盘数据。下一步应优先补齐项目归属，而非继续扩展 AI 或复杂管理功能。
