核心查询规则：

```sql
WHERE project_id = ?
  AND scheduled_date = ?
ORDER BY CASE priority
  WHEN 'P0' THEN 0
  WHEN 'P1' THEN 1
  WHEN 'P2' THEN 2
  WHEN 'P3' THEN 3
END ASC,
sort_order ASC
```

新增任务时，日期参数明确传入现有创建接口，不存在空日期插入。

编辑任务始终不会修改：

- `completed`；
- `project_id`；
- `created_at`；
- `id`。

仅当用户主动修改计划日期时，`scheduled_date` 才更新为目标日期，`sort_order` 同步调整到目标日期任务末尾；未改期时两者保持不变。

## 六、根因与最终修复

### 6.1 日期切换闪烁

- 区分首次加载和后台刷新；
- 日期切换时保留任务区域与空状态区域的稳定布局；
- 日期按钮直接触发目标日期查询；
- `useFocusEffect` 只处理 Tab 重新聚焦；
- 保留请求编号和日期双重校验；
- 日期文字使用稳定字号与布局。

### 6.2 Reload 与 Tab 黑闪

- 根导航、Tab 场景、页面和 Splash 统一为浅色背景；
- 根导航固定使用 `DefaultTheme`；
- 删除 Splash 的深色配置；
- 后台刷新不重新进入整页 loading；
- 四个 Tab 关闭懒加载并保留场景，避免首次切换时重新挂载造成黑闪。

### 6.3 今日页未同步

- 今日页增加 `useFocusEffect`；
- 每次重新进入今日 Tab 时重新查询 SQLite；
- 聚焦时重新生成本地当天日期；
- 首次进入显示 loading，后续聚焦静默刷新；
- 保留请求编号，避免旧查询覆盖新数据。

### 6.4 新增任务选择日期

- 新增和编辑模式均提供日期选择；
- 新增时默认回显计划页当前选中日期，若计划页位于过去日期则默认今天；
- 使用紧凑日历选择今天及未来日期；
- 保存时使用弹窗最终选中的日期；
- 保存成功后按实际保存日期刷新；
- 编辑改期时更新原任务记录，不复制任务，并保持完成状态不变；
- 日期切换不重建编辑弹窗状态，已输入标题保持不变。

### 6.5 固定浅色 UI

- `userInterfaceStyle` 固定为 `light`；
- 根导航固定 `DefaultTheme`；
- StatusBar 使用浅色页面对应的深色文字；
- Tab、四个页面和任务弹窗统一使用现有浅色样式；
- 删除业务页面中的 `useColorScheme()` 分支和 dark Palette；
- 保留弹窗暗色遮罩、按钮按压透明度、阴影、边框和优先级颜色。
